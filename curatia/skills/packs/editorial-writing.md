# Editorial Writing

## Curatia agents / flows
Editorial Studio generation/refinement, artifact transformations, channel adaptation.

## Adopted upstream skills
- `social-content`: platform-aware social writing and repurposing. Treat timing/frequency/performance claims as guidance that may become stale and should not be hard-coded as truth.
- `copy-editing`: primary refinement behavior. Preserve core message and author intent while improving clarity, voice, specificity, structure, and support.
- `copywriting`: reusable clarity, specificity, audience, and structure principles. Do not force conversion-copy patterns onto thought leadership.
- `humanizer`: useful natural-language cleanup and voice preservation.
- `stop-slop`: useful anti-AI-pattern review. Curatia's own voice/profile rules override overly rigid generic rules.
- `hooks`: specialist opening/hook patterns when the selected format benefits from a hook. Do not import YouTube-specific scoring as a universal quality measure.
- `outlines`: structured long-form/video planning when format requires an outline.
- `short-form`: repurposing patterns for Reels/Shorts/TikTok when source material exists.
- `content-cascade`: multi-channel repurposing pattern. Do not inherit creator-specific credentials or publishing behavior.

## Universal Curatia AI action
The primary AI action is universal.

Context = Editorial Intelligence + Audience + Channel + Format + Voice + selected Skills + Existing Artifact (when present).

If no artifact exists, create one. If an artifact exists, treat it as primary and preserve its intent while improving it.

After an artifact exists, transformations such as Tighten, Improve Structure, Adapt to Channel, and Strengthen Opening may route to narrower skills. Each transformation still receives channel, format, audience, voice, and artifact context.

Templates are skill guidance, not pre-filled editor content.
