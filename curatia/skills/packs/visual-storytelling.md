# Visual Storytelling

## Curatia agents / flows
Visual Direction, Generate Visual, carousel composition, diagrams/infographics.

## Adopted upstream skills
- `baoyu-infographic`: layout selection based on information structure and visual-summary patterns.
- `pixel-pal-carousel`: carousel slide-system mechanics when explicitly selected, not as Curatia's default aesthetic.
- `architecture-diagram`: specialist technical architecture visuals.
- `excalidraw`: whiteboard/diagram use cases.
- `frontend-design` and `design-review`: visual hierarchy/context gathering and design QA principles where relevant.

## Curatia rules
Visual is optional unless the selected format declares it required. Visual generation uses the Content Item's intelligence, artifact, channel, format, voice/brand context, and optional Visual Direction/reference material.

A generated visual retains prompt/provider/model provenance. A user-uploaded final visual is not presented as AI-generated.
