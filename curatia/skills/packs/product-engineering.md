# Product Engineering

## Curatia agents / flows
Platform engineering, integration work, debugging, QA, deployment, design review.

## Adopted upstream skills
- `systematic-debugging` / `investigate`: root-cause-first debugging and tight reproduction loops.
- `test-driven-development`: behavior-first testing pattern for product changes where practical.
- `qa` / `qa-only`: structured application QA and evidence.
- `review`: pre-landing structural review concepts.
- `github-pr-workflow`: branch/commit/CI/merge lifecycle reference.
- `document-release`: keep architecture/docs synchronized with shipped behavior.
- `frontend-design` / `design-review`: interface context and visual QA.
- `architecture-diagram`: system architecture communication.
- `careful`: destructive-operation safeguards.

## Curatia adaptation
Repository-specific commands, local paths, gstack/Hermes assumptions, and tool names are not runtime requirements unless Curatia actually provides them. Reuse the operating principles, not incompatible implementation details.
